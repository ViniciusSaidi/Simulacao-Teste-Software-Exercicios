
# 📦 Sistema de Estoque (TDD)

## 📖 Descrição

Este projeto implementa uma classe de gerenciamento de estoque em Python, utilizando a metodologia **Test-Driven Development (TDD)**.

O desenvolvimento foi realizado seguindo o ciclo **RED → GREEN → REFACTOR**, onde os testes são escritos antes da implementação do código, garantindo maior qualidade, confiabilidade e organização.

---

## ⚙️ Como instalar

Instale as dependências com:

```bash
pip install -r requirements.txt
```

---

## 🧪 Como testar

Execute os testes com:

```bash
pytest -v
```

---

## 📁 Estrutura do projeto

```bash
atividade07-sistema-estoque-tdd/
│
├── estoque.py            # Versão final (refactor)
├── estoque_red.py        # Versão inicial (fase RED)
├── estoque_green.py      # Implementação mínima (fase GREEN)
├── estoque_refactor.py   # Código refatorado (fase REFACTOR)
├── test_estoque.py       # Suite de testes
│
└── README.md
```
