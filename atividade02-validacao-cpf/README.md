# 🧾 Sistema de Validação de CPF

## 📖 Descrição

Este projeto implementa um sistema de validação e formatação de CPF em Python, desenvolvido como parte da disciplina de **Simulação e Teste de Software**.

O objetivo da atividade é aplicar boas práticas de testes unitários utilizando **pytest**, incluindo uso de fixtures, parametrização de testes, validação de exceções e organização seguindo o padrão AAA (Arrange, Act, Assert).

---

## ⚙️ Como instalar

Instale as dependências com:

```bash
pip install -r requirements.txt
```

---

## 🧪 Como testar

Execute os testes com:

```bash
pytest -v
```

---

## 📁 Estrutura do projeto

```bash
atividade02-validacao-cpf/
```
