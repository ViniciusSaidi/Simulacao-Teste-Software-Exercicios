# 📋 Sistema Task Manager

## 📖 Descrição

Este projeto implementa um sistema simples de gerenciamento de tarefas em Python. O objetivo é aplicar conceitos de testes automatizados utilizando **pytest**, incluindo testes de estado, ciclo de vida de objetos, uso de fixtures, mocks e stubs.

---

## ⚙️ Como instalar

Instale as dependências com:

```bash
pip install -r requirements.txt
```

---

## 🧪 Como testar

Execute os testes com:

```bash
pytest -v
```
